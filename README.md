## ❓ Common Problems and Fixes

**My tablet will not connect to the dashboard**
- Make sure both devices are on the same Wi-Fi network
- Restart rigdeck on your computer
- Restart your tablet browser

**Buttons do not work in the game**
- Check that vJoy is installed correctly
- Make sure you selected "vJoy Device" in the game controls
- Use the Windows Device Manager to check if the virtual joystick appears

**The GPS is blank or not loading**
- Close and reopen the game completely
- Make sure the game is on your primary monitor
- Check that the game is actively running a job

**The dashboard is laggy**
- Move your computer and tablet closer to your router
- Close other browser tabs on your tablet
- Lower the graphics quality in rigdeck settings
