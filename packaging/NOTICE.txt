Rig Deck -- what is in this folder that other people wrote
==========================================================

Rig Deck itself is open source, under the MIT License -- see LICENSE.txt beside
this file. The pieces below are bundled so that the installation needs no
internet connection and no build tools. Each is used unmodified, and each is
named here with where it came from.


runtime\
    Python 3.14.6, the "embeddable" build from python.org, unchanged.
    Python Software Foundation License, version 2 -- see runtime\LICENSE.txt.
    https://www.python.org/downloads/windows/

setup\vJoySetup-2.2.2.0-Win10-Win11.exe
    vJoy virtual joystick driver, originally by Shaul Eizikovich, in the
    2.2.2.0 build published by Brunner Elektronik. That build is EV-signed and
    Microsoft-attested, which is why it loads with Windows Memory Integrity
    left on -- the older 2.2.1 cannot.
    https://github.com/BrunnerInnovation/vJoy/releases/tag/v2.2.2.0

setup\scs-sdk-plugin-1.12.1.zip
    scs-sdk-plugin by RenCloud: the DLL the game loads to publish its telemetry.
    MIT License, Copyright (c) 2014 Hans.
    https://github.com/RenCloud/scs-sdk-plugin

tools\mapexport\bin\TsMap.dll, libdeflate.dll
    ts-map by Dario Wouters: the reader that parses the game's .scs archives.
    MIT License, Copyright (c) 2017 Dario Wouters.
    https://github.com/dariowouters/ts-map
    MapExport.exe beside it is Rig Deck's own headless driver for it.

tools\mapexport\bin\Newtonsoft.Json.dll
    Json.NET by James Newton-King. MIT License.
    https://github.com/JamesNK/Newtonsoft.Json

the tablet's GPS is read out of your own copy of the game, on your own PC, by
the installer. Nothing about it leaves this machine.
